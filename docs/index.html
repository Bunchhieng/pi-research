capabilities

Everything you need
to run research at scale.

Designed for tight loops between AI agents and your codebase. Every worktree is a clean experiment.

⊞
Parallel Worktrees

Spawn N isolated git worktrees in one command. Each gets its own branch, directory, and pi session — zero interference between experiments.

⊟
Tmux Orchestration

Multi-split mode auto-layouts panes with even-horizontal or tiled views. Attach, detach, and re-attach to any live session by slug.

⊘
Smart Cleanup

Interactive or batch removal of merged worktrees and their branches. Distinguishes merged vs. unmerged — never accidentally deletes live work.

⊕
Session Dashboard

Live table of all active sessions with age, tmux attachment state, and experiment counts parsed from autoresearch.jsonl.

reference

Commands

Everything runs as a single top-level command with intuitive subcommands.

pi-research [goal] — single worktree

Create one worktree on a timestamped autoresearch/* branch and launch pi. Goal becomes part of the branch name.

pi-research -s N [goal] — multi-split mode

Create N worktrees in parallel and open them in tmux splits. Layout auto-selects based on count.

pi-research status

Print a live dashboard of all active research sessions — age, tmux state, kept vs. total experiments.

pi-research attach [slug]

Re-attach to a running tmux session. Opens an interactive picker when no slug is provided.

pi-research cleanup --all / [slug]

Remove merged worktrees. Interactive by default, --all skips prompts, or target a specific branch by slug.

setup

Install in 60 seconds.

One script handles everything. Safe to re-run — idempotent by design.

01
Clone the repo

Pull pi-research into your home directory (or wherever you keep tools).

git clone https://github.com/Bunchhieng/pi-research.git ~/pi-research
02
Run the installer

Installs pi-autoresearch, registers the pi skill package, and adds the shell alias.

cd ~/pi-research && ./install.sh
03
Reload your shell

Pick up the new alias from your profile.

source ~/.zshrc
